## What a post can contain

Headings, paragraphs, a short list, and links. The file lives in the repo as MDX, with `title`, `date`, `summary`, `tags`, and `draft` in the frontmatter. An assistant adds a file and opens a pull request. Nothing here is a memory or an opinion of Jake's.

- Drafts stay out of the RSS feed and the sitemap.
- A preview deploy can show the draft so the pull request is readable.
- Setting `draft` to false is what publishes the note.
