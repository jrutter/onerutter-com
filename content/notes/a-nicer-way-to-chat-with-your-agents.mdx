I use [Orca](https://www.onorca.dev/) at work and at home, mostly in local terminal sessions. I love driving agents from the terminal. Native Chat is the bit I want to try properly next: a chat surface for the sessions that support it, while I keep that terminal workflow.

## What it is

Native Chat gives a supported agent session a structured transcript and a composer. I can stay in the terminal, and I can move a supported conversation between chat and the terminal. On those sessions, file diffs and tool progress show in the thread, and I can queue a follow-up while the agent is still going.

Not every session becomes a structured chat. Unsupported agents stay terminal-backed, and WSL and SSH sessions do too. I've not done a remote Orca session yet. For now this is about the local sessions I already run.

## Why it matters to me

I tried the mobile experience once, and I found it cool. The feel was close to working with remote cloud agents in Grok Bot and in Cursor. I've not used desktop Native Chat yet. I want to try it properly on my local desktop, beside the terminal sessions I already run. I'm not switching how I work. I just want to see whether that chat makes those local sessions nicer to come back to.

How it works is in the [Native Chat docs](https://www.onorca.dev/docs/agents/native-chat).
