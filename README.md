# onerutter.com

A plan and a design mockup for Jake Rutter's personal site. The Next.js app is not built yet. [PLAN.md](PLAN.md) is the review: what we borrow from the reference site, the sitemap, how notes get added, which copy is real, and the open questions.

The mockups are static HTML in `mockups/`.

```bash
python3 -m http.server 4173 --directory mockups
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).

- Home, story, lab, notes, a sample note, and a style guide
- Desktop and mobile screenshots from the design review live with the review artifacts, not in this folder
